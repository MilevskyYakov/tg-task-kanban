# Vendored fonts

Local runtime font assets for visual foundation v2.

- Inter variable (Cyrillic and Latin), Fontsource 5.2.8.
- Newsreader variable (Latin), Fontsource 5.2.8.
- IBM Plex Mono 500 and 700 (Cyrillic and Latin), Google Fonts v20.

All families use SIL Open Font License 1.1; license texts are stored beside the assets.
