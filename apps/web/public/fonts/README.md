# Vendored fonts

The Tasca interface uses the local Manrope variable font (Latin and Cyrillic),
copied without modification from the accepted v0.7 design package. Its SIL OFL
1.1 license is `OFL-Manrope.txt`. The CSS fallback is `system-ui, sans-serif`.

The outlined wordmark is supplied separately as an SVG; Golos Text is not loaded
as an interface font. Historical foundation v2 assets are retained but no longer
referenced by runtime CSS:

- Inter variable (Cyrillic and Latin), Fontsource 5.2.8.
- Newsreader variable (Latin), Fontsource 5.2.8.
- IBM Plex Mono 500 and 700 (Cyrillic and Latin), Google Fonts v20.

All families use SIL Open Font License 1.1; license texts are stored beside the assets.
