# Таска — развитие стеклянного направления v0.4

Статус: локальная итерация для выбора, не утверждённая система и не внедрение. Последняя обратная связь владельца: C лучше остальных, затем B; A не подходит. Требование — перенять больше визуальных приёмов из предоставленных референсов, а не ограничиться белыми карточками на зелёном градиенте. Предыдущая рекомендация исполнителя выбрать B не является принятым решением.

## Изменение направления

Убраны непрозрачные белые контейнеры каждого раздела. Список объединён в одну стеклянную поверхность; глубину задают прозрачность, тонкие светлые края, мягкие блики и более сложный цветовой фон. Типографика остаётся лёгкой. Чужие фотографии, логотипы и медицинские показатели не копируются.

- **C4 — цельное зелёное стекло:** глубокая зелёная рабочая область, светлый текст и прозрачная панель. Это намеренно более тёмная цветовая композиция для обсуждения, не разрешение вводить новую системную тёмную тему. Оболочка Telegram и нижняя навигация в макете остаются светлыми.
- **C5 — опаловое стекло:** светлая оболочка, цвет и блики внутри общей поверхности списка, тёплый акцент рядом с зелёным. Только существующие счётчики разделов набраны точечным Doto; новые аналитические показатели не добавлены.

Состав функций, порядок задач, поиск/фильтры, группировка/вид и нижняя навигация сохранены. Все данные синтетические. Код, production и настройки Telegram не менялись.

## Проверка и границы

Просмотрены фактические рендеры обоих вариантов и узкие PNG. На 320 px длинные названия могут переноситься; метаданные, счётчики и действия не обрезаны. Проверка дерева `.pen` через Python с `assert` подтвердила одинаковые четыре названия задач и наличие обязательных контролов во всех четырёх новых экранах.

На настоящих PNG дополнительно измерен контраст метаданных относительно фоновых пикселей непосредственно под строками: C4 — 6.06 / 9.56 / 9.04 / 9.04; C5 — 5.51 / 8.98 / 8.30 / 8.77. Это ограниченная проверка статического растра, не полный WCAG-аудит и не гарантия всех состояний динамического backdrop.

Doto используется только для цифр, не для кириллицы. Google Fonts подтверждает SIL OFL 1.1, Latin и веса 100–900: https://raw.githubusercontent.com/google/fonts/main/ofl/doto/METADATA.pb ; лицензия: https://raw.githubusercontent.com/google/fonts/main/ofl/doto/OFL.txt . Шрифтовой файл в runtime не устанавливался. Остальной текст — Inter из принятой основы проекта. При отказе от точечных счётчиков используется Inter без потери смысла.

В v0.4 ещё не перенесены детали задачи, создание, настройки, канбан и полная матрица состояний; старые пустое/ошибочное состояния B не считаются проверкой C4/C5. Производительность blur в Telegram, реальные взаимодействия, 200% текста, keyboard/focus, fallback шрифтов и device-приёмка не проверялись. Финальная айдентика, малые аватары, SVG/монохромные варианты и полный handoff #133 остаются открытыми. Выбор варианта не означает автоматический запуск внедрения или публикации.
