Это архив принятого подготовительного этапа. Указанные ниже ограничения разрешения и SHA-256 относятся к тому этапу; после него владелец отдельно разрешил реализацию и `/taskfinish`. Актуальный статус кандидата и проверок приложения: [отчёт реализации](../../../docs/issue-177-implementation.md). HTML и его проверки не заменяют приёмку приложения.

## Открыть

Откройте `index.html` в браузере прямо из этого каталога. Сервер, сборка и npm-зависимости не нужны. Сохраните расположение файла внутри репозитория: он использует действующий `apps/web/src/style.css` и локальный Manrope из `apps/web/public/fonts/`.

Абсолютный путь текущего worktree:

`/Users/milevsky.yakov/orca/workspaces/tg-task-kanban/issue-177/artifacts/ux/issue-177/index.html`

По умолчанию открыта матрица. `index.html?view=list` открывает список. На странице доступны:

- переключение списка/матрицы, общие поиск, «Мои/Все» и условия оценки;
- сворачиваемое «Не разобрано», четыре категории и открытие исходной карточки;
- до трёх задач внутри каждого квадранта; «Ещё N» открывает полный список категории в отдельном окне, а возврат из карточки восстанавливает этот список;
- изменение двух признаков, частичная оценка, общий сброс, применение и отмена;
- создание демонстрационной задачи с исходно неизвестной оценкой;
- «Режимы проверки»: 320/390 px, текст 200%, loading/error/empty/read-only, имитация ошибки сохранения и конфликта;
- поле комментария для проверки фокуса и длинного ввода, без отправки.

Все данные вымышлены. Изменения сохраняются только в памяти страницы до перезагрузки. Канбан — существующая поверхность вне этого макета, его переключатель отключён. Панель фильтров демонстрирует только семантику #177, не заменяет дизайн полной панели #181.

Макет не связан с API, DB, Telegram или MCP. Сообщение «Сохранено в демо» не доказывает работу приложения. Ошибка/конфликт — управляемые визуальные состояния, не интеграционные тесты.

## Воспроизведение проверки

Из корня репозитория:

```sh
python3 artifacts/ux/issue-177/check.py
```

Нужны уже установленные Python Playwright и Chrome. Скрипт не устанавливает зависимости. По умолчанию использует `/Applications/Google Chrome.app/Contents/MacOS/Google Chrome`; другой установленный executable можно указать через `PROTOTYPE_CHROME`.

Браузер запускается headless, с отдельным временным контекстом, без личного профиля. HTTP/HTTPS-запросы блокируются; CSS и шрифт загружаются через `file://`. Вывод и скриншоты находятся в `artifacts/visual-evidence/issue-177/` (ignored evidence внутри task-workspace).

- Проверены порядок четырёх категорий, unknown, отсутствие дублей в списке, фильтры, `done` и исключение архива. В квадрантах проверены лимит в три задачи, порядок по сроку, «Ещё N» только при переполнении и отсутствие повторных названий категорий. Поиск и «Мои» пересчитывают превью и кнопку; ровно три задачи показываются без кнопки.
- Проверены отмена и Escape, возврат фокуса, Tab при нативном modal dialog, демо-ошибка/конфликт и read-only.
- Проверены ширины 320/390 px, длинный текст, перестройка матрицы в одну колонку при 200%, доступность нижних действий прокручиваемого dialog. Viewport 320×360 проверяет доступность поля при уменьшении высоты, **не настоящую экранную клавиатуру Telegram/iOS**.
- Inline JavaScript проверен через `node --check`: exit 0. `git diff --check`: exit 0; исходники приложения не менялись. Новые файлы ещё untracked, поэтому `git diff --check` сам по себе не проверяет их как tracked diff.
- Визуально просмотрены список, матрица, карточка, окно оценки 320/390, крупный текст и нижние действия dialog. После просмотра исправлен перенос заголовка «Задачи» при 200%, убрано лишнее поле карточки и показан локальный выбор в конфликте.
- По уточнению владельца сохранены общая рамка, пересекающиеся разделители, важность по столбцам и срочность по строкам. Вместо счётчиков и повторяющихся заголовков в ячейках размещены задачи; отдельный список снизу удалён. При переходе в одну колонку подписи осей скрываются и появляются названия категорий. Новые рендеры 320/390 px просмотрены; итоговый полный прогон включает проверки осей, геометрии и разделителей.
- Проверены открытие полного списка через Enter, доступ к задаче вне превью, возврат из карточки в список и восстановление фокуса. Escape и кнопка закрытия возвращают фокус на «Ещё N». Полный список проверен при 320 px и 200% текста, включая прокрутку до последней задачи. Для наглядной проверки переполнения добавлены три вымышленные задачи; активных демонстрационных задач теперь 13.

Первое раннее измерение сетки при переключении текста не подтвердило одну колонку; отдельная диагностика показала корректный размер 296px и одну колонку. Итоговый тест явно ждёт фактической перестройки. В проверке native dialog учтён наблюдавшийся переход фокуса в браузерную панель (DOM сообщает BODY); фоновые controls по-прежнему недоступны. Визуальная проверка полного списка при 200% выявила переполнение длинных слов внутри dialog, не видимое проверке ширины документа. Перенос исправлен на общем контейнере dialog; проверка теперь учитывает ширину dialog и текста строк, а не только страницы. Итоговый полный прогон выполнен после этих уточнений и последней правки HTML.
