## Визуальные решения

Сохранена белая editorial-система: Newsreader для заголовков, Inter для интерфейса, IBM Plex Mono для адреса и ключа. Списки и вход из аккаунта сохраняют нижнюю навигацию; форма, выдача ключа и восстановление результата изолированы от глобального «+». Выбор досок и отзыв используют собственные sheets.

Форма показывает заполненный пример с режимом изменения, а не начальные значения. Начальное состояние остаётся безопасным: пустое имя, ни одной выбранной доски, только чтение, создание недоступно до валидного ввода. Это и остальные состояния загрузки, offline, потери доступа, валидации, выхода без сохранения ключа и ошибки отзыва описаны в разделе 7 контракта; отдельный PNG каждого сочетания не создавался.

Данные подключений и досок демонстрационные. `https://example.invalid/mcp` обозначен как пример, не production URL. Значения в блоках ключа заведомо демонстрационные, не credential и не нормативный формат токена. Реальные значения должны переноситься полностью без обрезания; блок растёт по содержимому, экран прокручивается. Макет ошибки копирования показывает прокрученную область выдачи ключа.
