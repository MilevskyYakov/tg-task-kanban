## Предложенные значения, не утверждённые токены

- Зелёный: `#11764B`; молочный: `#F7F5EF`; основной текст: `#202A24`.
- Вторичный текст: `#626C64`; мягкая поверхность: `#E9EFE6`; декоративный акцент: `#DDEC9A`.
- Ошибка/просрочка: `#A33D32` на `#F8EDE8`, с текстом и иконкой.
- Словесное написание и крупные заголовки: Golos Text; интерфейс: Inter. Никаких отдельных символов бренда пока не утверждено.
- Поддерживается существующее светлое оформление. Инверсное приветствие не означает внедрение тёмной темы приложения.

Расчёт контраста по относительной яркости sRGB: зелёный/молочный 5.18:1; белый/зелёный 5.65:1; основной текст/молочный 13.58:1; вторичный текст/молочный 5.01:1; ошибка/мягкий фон ошибки 5.59:1. Декоративный светло-зелёный на зелёном даёт 4.45:1: допустим для показанной крупной жирной латинской надписи, не для мелкого обычного текста.

Golos Text: SIL OFL 1.1; метаданные Google Fonts подтверждают кириллицу, латиницу и веса 400–900. Источники: https://raw.githubusercontent.com/google/fonts/main/ofl/golostext/METADATA.pb и https://raw.githubusercontent.com/google/fonts/main/ofl/golostext/OFL.txt. Inter уже поставляется в проекте с лицензией: `apps/web/public/fonts/README.md`. Иконки в Pen — Lucide; при внедрении сохранять локальный язык иконок проекта, не добавлять библиотеку автоматически.

## Открытая приёмка

Нужны решение владельца по направлению, проверенный рендер лендинга, мобильная версия лендинга, граница 320 px, пустые/ошибочные/загрузочные состояния и сохранение autosave-контракта. Читаемость аватара при 32/40/64 px пока не проверена; крупный круглый кроп не доказывает её. Только после этой проверки решается необходимость компактного знака. Финальные SVG, монохромные варианты, шрифтовые активы/лицензии для передачи и руководство не завершены. Issue #133 не закрыта.
