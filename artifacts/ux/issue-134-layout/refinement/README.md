# #134 — визуальная итерация главного экрана и создания задачи

Статус этого этапа: локально реализовано и проверено, получена положительная оценка Якова. После отдельного разрешения направление распространено на остальные поверхности; актуальный результат находится в [../rollout/README.md](../rollout/README.md). Ниже сохранены evidence и границы первой итерации двух экранов.

## Основание и результат

Пользователь отверг слитную поверхность списка и попросил отдельные карточки, больше округлений и мягкой глубины, новые нижние иконки и более цельную форму создания. В качестве визуального основания повторно предоставлен Superpower от rondesignlab. Чужие изображения не используются в приложении. Два чистых референса и сравнительный лист сохранены только локально и исключены из Git; скриншоты с личным интерфейсом браузера не копировались.

- Список: отдельные светлые карточки с зазором, скруглением и многослойной тенью. Локальный цветовой акцент у срочных задач; текстовая метка «Срочно» сохранена.
- Панель: плавающая округлая поверхность, обновлённые иконки, выделение активного раздела, объёмная кнопка добавления.
- Создание: название и описание объединены в основном блоке; описание больше не скрыто в «Дополнительно». Проект, исполнитель, срок, статус и доска представлены отдельными округлыми строками. Приоритет и уведомление остаются в раскрываемом блоке.
- Основное и второстепенное действия различаются по заливке; появились светлый край и мягкие тени. Добавлены отступы прокрутки для полей и кнопок над закреплённым низом.
- Поиск, фильтры, канбан B, API и бизнес-логика не заменены. Новых зависимостей нет.

## Проверки

- `npm run lint` (включает typecheck): пройдено, `lint.log`.
- `npm run test`: 32 unit и 13 интеграционных тестов, ошибок нет, `tests.log`. Использована отдельная локальная БД `tasca_issue134_checks`, collation `en_US.UTF-8`; production не затронут.
- `npm run build`: пройдено, `build.log`.
- `npm run test:visual`: 89 проверок пройдено, `visual-final.log`. После последней локальной CSS-коррекции строки без иконки повторно пройдены все 11 проверок создания, `create-final.log`, и сборка.
- Дополнены проверки зазоров карточек, заголовка формы, доступности низа при прокрутке, сохранения описания при ошибке и его передачи в запросе создания.
- Контраст текста списка проверен на наиболее тёмном пикселе отрисованной поверхности без текста: основной ≥7,754:1, вторичный ≥6,027:1, просрочка ≥4,877:1. Белый текст на самом светлом конце основной кнопки — 5,296:1. Это ограниченная проверка, не полный WCAG-аудит. Результаты и хеши снимков: `verification.json`.

Первая попытка полного browser-прогона остановилась из-за отсутствующей переменной `TEST_DATABASE_URL`. После проверки существующей изолированной БД выполнен успешный полный прогон; значения секретов не читались.

Главный экран и создание получили положительную оценку владельца. Новые поверхности следующего этапа, реальные Telegram iOS/Android и экранная клавиатура устройства требуют отдельной проверки. Браузерная эмуляция не заменяет устройство. Commit, push, merge и deploy не выполнялись.
