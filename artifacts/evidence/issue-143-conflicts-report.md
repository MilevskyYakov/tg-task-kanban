## Изменение

- Трёхстороннее сравнение исходной подтверждённой базы, текущего локального черновика и серверного состояния сохраняет независимые поля. Срок и status/blocker рассматриваются как связанные группы, чтобы не собирать невалидную комбинацию.
- Диалог показывает фактические локальные и серверные значения. Выбор сервера отбрасывает конфликтующие локальные поля, а не весь черновик. Выбор локальных значений проходит через существующую single-flight очередь с показанным `expectedVersion`.
- Подтверждённые значения согласованно обновляют baseline, version, draft, родительскую карточку и список. Поздний ответ не открывает заново уже закрытую карточку. Изменение, сделанное во время отправки resolution, остаётся в очереди.
- Неразрешённый конфликт приостанавливает autosave, в том числе на reconnect/blur/exit. «Решить позже» закрывает только диалог. Исходная база и версия сохраняются вместе с черновиком; после reload конфликт можно восстановить без слепого overwrite. Старые черновики без версии требуют явного выбора.
- Только `409` с `error: "version conflict"` и задачей нужной доски/ID открывает этот диалог. Checklist confirmation, прочие `409` и `403` не классифицируются как version conflict.
- REST/DB version guard, серверные права, isolation и публичные API не изменены. Новых зависимостей нет; manifest/lockfile не изменены.

1. `apps/web/test/tasks.test.ts` и `apps/web/visual/details.spec.ts`: синтетические данные, в browser-сценариях — mock API. Проверяются merge независимых полей, связанные группы, пауза очереди, очистка rejected draft, последующее редактирование с актуальной версией, новая правка во время resolution, клавиатура/focus, reload старого unversioned draft, отсутствие конфликтного диалога для других `409`/`403`.

Это не mock PATCH. Проверяются оба выбора, независимые локальное описание и серверный приоритет, «Решить позже» с новым вводом/reconnect/reload, новый конкурентный update до resolution, последующее редактирование, DB readback и два одновременных PATCH с одним `expectedVersion`: один получает `200`, второй — `409`.
