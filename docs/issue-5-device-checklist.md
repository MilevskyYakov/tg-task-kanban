# Issue #5 — device checklist

Проверить в production-like TMA после деплоя. Зафиксировать модель устройства, ОС, версию Telegram и результат.

## iOS Telegram

- [ ] Доска открывается со срезом «Мои».
- [ ] «Мои / Все» и «Список / Канбан» показывают один отфильтрованный набор.
- [ ] Все фильтры комбинируются; повторный вход восстанавливает набор для этой доски.
- [ ] Поиск находит название и описание; пустой результат читаем.
- [ ] Горизонтальный скролл канбана и вертикальный скролл страницы не блокируются.
- [ ] Долгое нажатие и перенос карточки меняют колонку.
- [ ] Select статуса меняет статус без drag-and-drop.
- [ ] Запрещённый переход откатывает карточку и показывает ошибку.
