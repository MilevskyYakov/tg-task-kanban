## Поведение

- «Без срока» сохраняет null, не создаёт скрытую дату или ложную просрочку.
- «Только дата» хранит календарную дату и IANA timezone отдельно от timestamp. Просрочка начинается на следующей календарной дате в сохранённом поясе; поездки и настройки публикаций не меняют границу.
- «Дата и время» требует оба поля. Существующие timestamps не переинтерпретируются как date-only. Редактирование других полей сохраняет секунды, миллисекунды и исходный момент при осеннем повторении часа; несуществующее весеннее время отклоняется.
- Все четыре начальных статуса сохраняются одной транзакцией. Для `done` используются общие права завершения, completion metadata и история создания; `waiting` требует ровно одно основание. Блокирующая задача должна быть активной и принадлежать той же доске.
- Повтор POST с тем же request ID и payload возвращает существующую задачу без повторной истории. Другой payload с тем же ID получает 409. Форма блокирует повторный submit и сохраняет ввод и ID при ошибке ответа.
- Списки, фильтры, детали и публикации учитывают date-only. Модель расписания повторений не изменена.
