## Воспроизводимый сценарий новой команды

Перед выполнением владелец отдельно выбирает разрешённые runtime/bot, синтетический чат/доски и точный live candidate SHA. Нужны незнакомые с интерфейсом участники A/B, реальные iOS и Android. Для каждой платформы записать модель, ОС, версию Telegram, дату и итог по каждому шагу; сейчас эти данные не предоставлены. Наблюдатель не подсказывает, где нажимать. Встроенной помощью пользоваться можно; устная подсказка означает «с помощью», а не самостоятельный PASS.

Недостаток evidence не объявляется продуктовым дефектом. Отсутствие второго участника исключено из blockers.
